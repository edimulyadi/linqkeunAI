# linqkeunAI — Mobile App

Flutter app (Android + iOS) for linqkeunAI, talking to the Next.js backend
in `apps/web`.

```bash
flutter pub get
flutter run --dart-define=API_BASE_URL=http://localhost:3000
```

See [`../../docs/MOBILE.md`](../../docs/MOBILE.md) for the full guide:
project structure, auth flow, running locally, and release builds for the
Play Store / App Store.
